# Architecture Design Skills

Reusable AI skills for this template are defined in the AI Skills Register
in [dsnAIAgentGuide.tex](dsnAIAgentGuide.tex).

Read that guide and select the applicable AIS from Table C.2,
labeled `Table:AISkills`. Read the authoritative sources and the
Context, Steps, and Acceptance linked for the selected AIS.
Apply the guide's shared rules, including `Rule:AITerminologyConsistency`.

Execute using [dsnAIImplementationWorkflow.tex](dsnAIImplementationWorkflow.tex),
including its decision about one or multiple agents.
The root architecture source is [dsnManual.tex](dsnManual.tex).
Follow [dsnDocumentGuide.tex](dsnDocumentGuide.tex) for authoring and building.

Keep skill definitions and architecture rules in the authoritative LaTeX sources.
When installing this skill in another directory, adjust these links to resolve
to the project's architecture sources.
